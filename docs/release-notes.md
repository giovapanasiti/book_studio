Book Studio — write chapters in markdown, keep a story bible, design the page
and the cover, export a print-ready PDF and an ePub.

## Downloads

| File | Platform |
|---|---|
| `book-studio_*_macos_universal.zip` | macOS (Apple Silicon + Intel) — unzip and drag to Applications; on first launch right-click → Open (the app is not notarized) |
| `book-studio_*_windows_amd64.zip` | Windows 10/11 — unzip and run `book-studio.exe` (needs the WebView2 runtime, preinstalled on Windows 11) |
| `book-studio_*_amd64.deb` | Debian / Ubuntu 24.04+ — `sudo apt install ./book-studio_*_amd64.deb` |
| `book-studio_*_linux_amd64.tar.gz` | Other Linux — portable binary, see the INSTALL file inside |

Arch Linux users: clone the repository and run `makepkg -si`.

## Highlights

- Markdown chapters with live preview, focus mode with synthesized
  typewriter sounds, and a full story bible (characters, world, plot
  threads, timeline, outline).
- Real typesetting: justified text, drop caps, running headers, folios,
  parts and interludes, unnumbered front/back matter, full-page image
  plates, and a two-pass table of contents.
- Freeform cover editor with system fonts; the cover exports exactly as
  designed (rendered at 300 dpi).
- Localized output: English, Italiano, Français, Español, Português,
  Deutsch — with custom chapter and contents labels.
- Exports: print-ready PDF and valid EPUB 3.
